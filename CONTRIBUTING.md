# Como contribuir

1. Abra uma issue citando RF, RN, D ou entrega relacionada.
2. Registre critérios de aceite e esclareça propostas ainda não ratificadas.
3. Crie uma branch curta: `docs/...`, `feat/...` ou `fix/...`.
4. Faça mudanças pequenas, revise o diff e atualize documentos afetados.
5. Abra pull request usando o modelo. Informe validação e limitações reais.

Não enviar dados de clientes, credenciais ou certificados. Usar exemplos fictícios. Alterações de regra comercial exigem atualização da especificação; alterações estruturais exigem ADR. Não há licença de software definida neste pacote.
